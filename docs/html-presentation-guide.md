# HTML 演示文稿使用指南 / HTML Presentation Guide / HTML-Präsentationsanleitung

适用于用 Presentation Director 生成的 Reveal.js HTML 演示文稿。  
For Reveal.js HTML decks generated by Presentation Director.  
Für Reveal.js-HTML-Präsentationen, die mit dem Presentation Director erstellt wurden.

---

## 中文

### 一、连接投影仪

1. 用 HDMI 或 VGA 线连接投影仪。
2. **Mac**：苹果菜单 → 系统设置 → 显示器 → 排列 → 取消勾选「镜像显示器」，选**扩展显示器**。  
   **Windows**：按 `Win + P` → 选**扩展**。
3. 确认笔记本和投影仪是两块独立的屏幕（扩展模式），而不是同一画面（镜像模式）。

> **为什么用扩展而不是镜像？**  
> 扩展模式下，投影仪显示幻灯片，老师笔记本显示演讲者注释。镜像模式下两块屏幕内容完全相同，学生也会看到注释窗口。

### 二、打开演示文稿

1. 找到生成的 `.html` 文件（通常在 `Decks/<任务名>/final/` 目录下）。
2. 直接双击，或把文件拖入 **Chrome** 或 **Edge** 浏览器窗口打开。
3. 把浏览器窗口拖到**投影仪对应的屏幕**上。

### 三、全屏显示

- 在 Reveal.js 窗口内按 **`F`** 键 → 进入全屏（推荐）。
- 或者：**Windows** 按 `F11`；**Mac** 按 `Cmd + Shift + F`。
- 退出全屏：按 `Esc`。

### 四、翻页

| 操作 | 说明 |
|------|------|
| `→` 或 `空格` | 下一张 |
| `←` | 上一张 |
| `Home` / `End` | 跳到第一张 / 最后一张 |
| 鼠标点击画面 | 下一张 |

### 五、演讲者注释（S 键）

1. 在投影仪那块屏幕的浏览器窗口里按 **`S`** 键。
2. 弹出**演讲者视图**窗口，把它拖到**老师笔记本屏幕**上。
3. 演讲者视图包含：
   - 当前幻灯片缩略图
   - **下一张幻灯片预览**（提前知道下一页内容）
   - **演讲注释**（备课时写好的提示）
   - 计时器

> **学生能看到注释吗？**  
> 不会。注释窗口是独立弹窗，只出现在按了 S 键的那台电脑上。投影仪画面不受影响。

### 六、打印讲义 / 导出 PDF

1. 在浏览器地址栏的 URL 末尾加上 `?print-pdf`，例如：
   ```
   file:///Users/.../final.html?print-pdf
   ```
2. 等页面重新加载（会变成竖排预览）。
3. 按 `Ctrl + P`（Windows）或 `Cmd + P`（Mac）打印。
4. 打印设置：**横向**、**无页眉页脚**、**背景图形勾选**。
5. 选「另存为 PDF」即可导出。

### 七、常见快捷键汇总

| 键 | 功能 |
|----|------|
| `F` | 全屏 / 退出全屏 |
| `S` | 打开演讲者注释窗口 |
| `→` / `空格` | 下一张 |
| `←` | 上一张 |
| `B` | 黑屏（暂停演示时遮挡画面） |
| `?` | 显示所有快捷键 |
| `Esc` | 退出全屏 / 返回幻灯片概览 |

## English

### 1. Connect the Projector

1. Connect via HDMI or VGA cable.
2. **Mac**: Apple menu → System Settings → Displays → Arrangement → uncheck **Mirror Displays**, choose **Extended Display**.  
   **Windows**: Press `Win + P` → select **Extend**.
3. Confirm you have two independent screens (laptop + projector), not mirrored.

> **Why Extend instead of Mirror?**  
> In extend mode the projector shows slides only; the speaker notes popup stays on your laptop. In mirror mode students would also see your notes window.

### 2. Open the Presentation

1. Locate the generated `.html` file (usually in `Decks/<task-name>/final/`).
2. Double-click it, or drag it into **Chrome** or **Edge**.
3. Drag the browser window onto the **projector screen**.

### 3. Go Fullscreen

- Press **`F`** inside the Reveal.js window (recommended).
- Or: **Windows** `F11` · **Mac** `Cmd + Shift + F`.
- Exit fullscreen: `Esc`.

### 4. Navigate Slides

| Key / Action | Effect |
|---|---|
| `→` or `Space` | Next slide |
| `←` | Previous slide |
| `Home` / `End` | First / last slide |
| Mouse click | Next slide |

### 5. Speaker Notes (S key)

1. With the browser focused on the projector screen, press **`S`**.
2. A **Speaker View** popup opens — drag it to your **laptop screen**.
3. Speaker View shows:
   - Current slide thumbnail
   - **Next slide preview**
   - **Speaker notes** (prepared prompts written during deck creation)
   - Timer

> **Will students see the notes?**  
> No. The notes popup is a separate window visible only on the machine where you pressed S. The projector display is unaffected.

### 6. Print Handouts / Export PDF

1. Add `?print-pdf` to the URL in the address bar:
   ```
   file:///Users/.../final.html?print-pdf
   ```
2. Wait for the page to reload (it switches to a vertical print layout).
3. Press `Ctrl + P` (Windows) or `Cmd + P` (Mac).
4. Settings: **Landscape**, **no headers/footers**, **background graphics on**.
5. Choose **Save as PDF**.

### 7. Keyboard Shortcuts

| Key | Function |
|-----|----------|
| `F` | Toggle fullscreen |
| `S` | Open speaker notes window |
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `B` | Black screen (pause / hide content) |
| `?` | Show all shortcuts |
| `Esc` | Exit fullscreen / slide overview |

## Deutsch

### 1. Projektor verbinden

1. HDMI- oder VGA-Kabel anschließen.
2. **Mac**: Apple-Menü → Systemeinstellungen → Displays → Anordnung → „Displays spiegeln" **deaktivieren**, **Erweiterter Desktop** aktivieren.  
   **Windows**: `Win + P` drücken → **Erweitern** wählen.
3. Sicherstellen, dass Laptop und Projektor zwei unabhängige Bildschirme sind (kein Spiegelmodus).

> **Warum Erweitern statt Spiegeln?**  
> Im erweiterten Modus zeigt der Projektor nur die Folien; das Moderatoren-Fenster bleibt auf dem Laptop. Im Spiegelmodus würden die Notizen auch auf der Leinwand erscheinen.

### 2. Präsentation öffnen

1. Die erzeugte `.html`-Datei im Ordner `Decks/<Aufgabenname>/final/` öffnen.
2. Datei doppelklicken oder in **Chrome** bzw. **Edge** ziehen.
3. Das Browserfenster auf den **Projektor-Bildschirm** ziehen.

### 3. Vollbild aktivieren

- Im Reveal.js-Fenster die Taste **`F`** drücken (empfohlen).
- Alternativ: **Windows** `F11` · **Mac** `Cmd + Shift + F`.
- Vollbild beenden: `Esc`.

### 4. Folien wechseln

| Taste / Aktion | Funktion |
|---|---|
| `→` oder `Leertaste` | Nächste Folie |
| `←` | Vorherige Folie |
| `Home` / `End` | Erste / letzte Folie |
| Mausklick | Nächste Folie |

### 5. Moderationsnotizen (S-Taste)

1. Browser auf dem Projektor-Bildschirm fokussieren, dann **`S`** drücken.
2. Ein **Moderatoren-Fenster** öffnet sich — auf den **Laptop-Bildschirm** ziehen.
3. Das Moderatoren-Fenster enthält:
   - Miniaturansicht der aktuellen Folie
   - **Vorschau der nächsten Folie**
   - **Moderationsnotizen** (während der Erstellung hinterlegte Hinweise)
   - Timer

> **Sehen die Schüler die Notizen?**  
> Nein. Das Notizfenster ist ein separates Popup, das nur auf dem Rechner erscheint, auf dem S gedrückt wurde. Der Projektor zeigt weiterhin nur die Folien.

### 6. Handout drucken / PDF exportieren

1. `?print-pdf` an die URL anhängen:
   ```
   file:///Users/.../final.html?print-pdf
   ```
2. Seite neu laden lassen (wechselt in vertikales Drucklayout).
3. `Strg + P` (Windows) oder `Cmd + P` (Mac) drücken.
4. Einstellungen: **Querformat**, **keine Kopf-/Fußzeilen**, **Hintergrundgrafiken aktivieren**.
5. **Als PDF speichern** wählen.

### 7. Tastenkürzel-Übersicht

| Taste | Funktion |
|-------|----------|
| `F` | Vollbild ein/aus |
| `S` | Moderationsnotizen öffnen |
| `→` / `Leertaste` | Nächste Folie |
| `←` | Vorherige Folie |
| `B` | Schwarzbild (Pause / Inhalt verbergen) |
| `?` | Alle Kürzel anzeigen |
| `Esc` | Vollbild beenden / Folienübersicht |
